# 部署安全基线

- 发布前执行 `npm run verify`；该命令会阻止存在高危生产依赖、测试失败或包体预算超限的构建。
- 浏览器导入只接受受信任的业务文件，并限制文件数、单文件大小、总大小、工作表数和总行数。
- `vendor/xlsx-0.20.3.tgz` 是固定版本的 SheetJS CE 发布包；升级时必须同步更新校验值并重新运行完整验证。
- 当前 `npm audit` 的剩余告警来自仅用于开发和构建的 `vinext -> image-size`，不会进入浏览器运行时或线上生产依赖审计。上游尚无无漏洞版本，因此不得使用 `npm audit fix --force` 回退构建工具。
- 开发和构建环境只处理仓库内受信任的图片资源；不要把外部不受信任的 ICNS、JXL 或 HEIF 文件交给该工具链解析。

线上发布以 `npm audit --omit=dev` 的结果为准，并由 `npm run verify` 自动执行。
